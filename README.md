# 🤖 بوت تيليجرام متجر أنيس (Anees Store Bot)

بوت تيليجرام متجر إلكتروني مبني بلغة بايثون باستخدام مكتبة **pyTelegramBotAPI** وقاعدة بيانات **MongoDB**، متصل بواجهة برمجة تطبيقات (API) خارجية لبيع المنتجات والاشتراكات الرقمية بنظامي التسليم الفوري واليدوي.

---

## ✨ المميزات الرئيسية

1. **الأمان والتخزين في MongoDB:**
   - كود الاتصال المشفر (`connection_code`) يتم حفظه واسترجاعه دائماً من قاعدة بيانات MongoDB.
   - **لا يوجد أي `API_KEY` أو عنوان API ثابت داخل كود البايثون نهائياً.**
   - فك تشفير الكود واستخراج الرابط والمفتاح يتم ديناميكياً أثناء التشغيل.

2. **واجهة عميل بسيطة وأنيقة:**
   - أمر `/start` يحتوي على زرين رئيسيين فقط كما هو مطلوب:
     - 🛒 **المنتجات**
     - 💰 **رصيدي**
   - استخدام تنسيق `parse_mode="HTML"` في جميع رسائل وتنبيهات البوت.

3. **كتالوج المنتجات ونظام الصفحات (Pagination):**
   - يعرض المنتجات من `GET /products` بأزرار تفاعلية تشمل:
     - ⚡ رمز **التسليم الفوري** للمنتجات التلقائية (`is_manual = false`).
     - 🤝 رمز **التسليم اليدوي** للمنتجات التي تحتاج تسليماً من الإدارة (`is_manual = true`).
     - اسم المنتج وسعره.
   - تصفح مرن بالصفحات لتجنب تجاوز حدود تيليجرام (حيث يحتوي المتجر على أكثر من 100 منتج).

4. **نظام الشراء والتسليم الذكي:**
   - **المنتجات الفورية (Instant):** ترسل الأكواد فوراً للعميل بعد الشراء داخل تنسيق `<code>`.
   - **المنتجات اليدوية (Manual):** تظهر للعميل رسالة: *"✅ تم استلام طلبك! سيتم التسليم خلال دقائق."* مع رقم الطلب.
   - **منتجات ChatGPT Business:** تطلب من العميل إدخال بريده الإلكتروني لإرسال دعوة التفعيل تلقائياً.
   - **إشعار الأدمن (`notify_admin`):** يتم إرسال إشعار فوري للأدمن في الحالتين يحتوي على كافة تفاصيل الطلب وهوية المشتري.

5. **المزامنة الحية للمخزون (Sync):**
   - أمر `/sync` للأدمن لجلب التغييرات من `GET /changes?since=cursor` وتحديث المخزون المحلي وحفظ الكورسور الجديد في MongoDB.
   - خيط خلفي (Background Worker) يعمل تلقائياً كل 30 ثانية لتحديث المخزون وإشعار العملاء في حال اكتمال طلباتهم اليدوية من قبل المورد.

6. **لوحة تحكم الأدمن:**
   - `/sync`: فحص التحديثات والمزامنة.
   - `/api_balance`: فحص رصيد حسابك في الـ API.
   - `/orders`: عرض سجل الطلبات الأخيرة.
   - `/add_balance [ID] [AMOUNT]`: شحن رصيد لمستخدم.
   - `/set_conn [CODE]`: تغيير كود الاتصال في MongoDB مباشرة دون إيقاف البوت.

## 📁 هيكلية ملفات المشروع

```text
Anees Store/
├── docs/
│   └── HOW_TO_RUN.md   # دليل التشغيل المفصل خطوة بخطوة للمبتدئين

├── database.py         # الاتصال بـ MongoDB وإدارة الإعدادات، الأرصدة، الطلبات والمخزون

├── config.py           # تحميل الإعدادات وتخصيص المتغيرات
├── test_bot.py         # اختبارات آلية شاملة للتحقق من سلامة البوت والربط
├── requirements.txt    # الحزم والمكتبات المطلوبة
├── .env                # ملف المتغيرات وبيانات التشغيل
├── .env.example        # قالب توضيحي لملف الإعدادات
└── README.md           # دليل التثبيت والتشغيل
```

## 🚀 التثبيت والتشغيل

### 1. تثبيت المتطلبات:
تأكد من وجود بايثون ثم نفّذ الأمر التالي:
```bash
pip install -r requirements.txt
```

### 2. إعداد ملف `.env`:
قم بفتح ملف `.env` ووضع توكن البوت ومعرف الأدمن:
```env
# توكن البوت من @BotFather
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz

# آيدي حسابك في تيليجرام (احصل عليه من @userinfobot)
ADMIN_ID=123456789

# رابط MongoDB (محلي أو من MongoDB Atlas السحابي المجاني)
MONGO_URI=mongodb://localhost:27017/
DB_NAME=anees_store

# كود الاتصال (يتم حفظه تلقائياً في MongoDB ولا يظهر أي مفتاح في الكود)
INITIAL_CONNECTION_CODE=conn_eyJrIjoic2tfOTEwMTA1Y2I4ZDVkNWFjOTVjNzA4Njg4Y2I2NjhmNmEzMjc2ODVhMDFlYmNiMjA3IiwidSI6Imh0dHBzOi8vaW5zMjExMjEzMS1md2YxLm9ucmVuZGVyLmNvbS84ZjcxYWVkZDM0OTRlMDQyYmIwNjQwOGY1MGI3ZjkzOCJ9

# نظام الرصيد الداخلي (False يتيح الشراء المباشر عبر رصيد الـ API)
REQUIRE_USER_BALANCE=False

# فاصل المزامنة التلقائية بالثواني
POLL_INTERVAL_SECONDS=30
```

> 💡 **ملاحظة بخصوص MongoDB:** البوت يدعم الاتصال المباشر بقاعدة بيانات MongoDB المحلية أو السحابية (Atlas). وفي حال لم تكن خدمة MongoDB تعمل محلياً أثناء التطوير، ينتقل البوت تلقائياً إلى نظام محاكاة آمن لضمان عدم توقف العمل.

### 3. تشغيل الاختبارات الآلية للتأكد:
```bash
python test_bot.py
```

### 4. تشغيل البوت:
```bash
python bot.py
```

## 🛠️ أوامر البوت

| الأمر | المستخدم | الوصف |
| :--- | :--- | :--- |
| `/start` | الجميع | فتح القائمة الرئيسية (🛒 المنتجات + 💰 رصيدي) |
| `/products` أو زر المنتجات | الجميع | فتح كتالوج المنتجات مع أسعارها ونوع تسليمها |
| `/balance` أو زر رصيدي | الجميع | عرض بيانات رصيد الحساب والطلبات |
| `/sync` | الأدمن فقط | مزامنة أي تغييرات في المخزون وحفظ Cursor الجديد |
| `/api_balance` | الأدمن فقط | فحص رصيد حسابك المتبقي في API المتجر |
| `/orders` | الأدمن فقط | عرض سجل الطلبات الأخيرة |
| `/add_balance [ID] [AMOUNT]`| الأدمن فقط | شحن رصيد إضافي لأي مستخدم داخل المتجر |
| `/set_conn [CODE]` | الأدمن فقط | تحديث كود الاتصال وتخزينه في MongoDB مباشرة |
| `/admin` أو `/help` | الأدمن | لوحة مساعدة تحتوي على كافة أوامر الإدارة |
