## 1. المتطلبات الأساسية

- جهاز كمبيوتر (Windows / Linux / Mac) أو سيرفر VPS.
- مثبت عليه لغة **Python 3.10** أو أحدث.
- حساب في تطبيق تيليجرام.

## الخطوة 1: إنشاء البوت والحصول على التوكن (Bot Token)

لإنشاء بوت رسمي على تيليجرام:

1. افتح تطبيق تيليجرام وابحث عن الحساب الرسمي: [**@BotFather**](https://t.me/BotFather).
2. اضغط على **Start** أو أرسل الأمر:
   ```text
   /newbot
   ```
3. سيطلب منك اسم البوت الظاهر (Name)، مثال:
   ```text
   متجر أنيس الرقمي
   ```
4. سيطلب منك اسم المستخدم للبوت (Username) والذي يجب أن ينتهي بـ `bot`، مثال:
   ```text
   AneesStore_bot
   ```
5. سيرسل لك BotFather رسالة تهنئة تحتوي على **رمز التوكن (API Token)**، وسيكون شبيهاً بهذا:
   ```text
   7123456789:AAFlkjhGFEDCba1234567890qwertyuiop
   ```
   ⚠️ *احفظ هذا التوكن ولا تشاركه مع أحد.*

## الخطوة 2: معرفة الآيدي الخاص بك في تيليجرام (Admin ID)

يحتاج البوت لمعرفة آيدي حسابك لكي يرسل لك إشعارات الطلبات (`notify_admin`) ويمنحك صلاحيات الأوامر الإدارية مثل `/sync` و `/api_balance`:

1. في تيليجرام، ابحث عن أحد بوتات كشف الآيدي مثل: [**@userinfobot**](https://t.me/userinfobot) أو [**@raw_data_bot**](https://t.me/raw_data_bot).
2. اضغط **Start**.
3. سيرد عليك البوت برقم الآيدي الخاص بك (Id)، مثال:
   ```text
   123456789
   ```

## الخطوة 3: إعداد ملف المتغيرات `.env`

داخل مجلد المشروع، ستجد ملفاً باسم `.env` (إذا لم يكن ظاهراً، تأكد من إظهار الملفات المخفية، أو انسخ محتوى `.env.example` إلى `.env`).

افتح ملف `.env` بأي محرر نصوص (مثل Notepad أو VS Code) وعدّل القيمتين التاليتين:

```env
# 1. ضع توكن البوت الذي نسخته من BotFather
BOT_TOKEN=7123456789:AAFlkjhGFEDCba1234567890qwertyuiop

# 2. ضع آيدي حسابك الذي استخرجته في الخطوة 2
ADMIN_ID=123456789

# 3. إعدادات قاعدة البيانات (اتركها كما هي إذا كنت تشغل محلياً)
MONGO_URI=mongodb://localhost:27017/
DB_NAME=anees_store

# 4. كود الاتصال بالمتجر (موجود مسبقاً ولا تعدله إلا إذا تغير المتجر)
INITIAL_CONNECTION_CODE=conn_eyJrIjoic2tfOTEwMTA1Y2I4ZDVkNWFjOTVjNzA4Njg4Y2I2NjhmNmEzMjc2ODVhMDFlYmNiMjA3IiwidSI6Imh0dHBzOi8vaW5zMjExMjEzMS1md2YxLm9ucmVuZGVyLmNvbS84ZjcxYWVkZDM0OTRlMDQyYmIwNjQwOGY1MGI3ZjkzOCJ9

# 5. نظام رصيد المستخدم الداخلي:
# False: يتم طلب الشراء مباشرة من المتجر الخارجي بالاعتماد على رصيدك في الـ API.
# True: يلزم العميل شحن رصيد في البوت أولاً بواسطة الأدمن قبل الشراء.
REQUIRE_USER_BALANCE=False

# 6. المزامنة التلقائية للستوك كل 30 ثانية
POLL_INTERVAL_SECONDS=30
PRODUCTS_PER_PAGE=8
```

## الخطوة 4: إعداد قاعدة بيانات MongoDB

يوفر البوت ثلاث خيارات سهلة ومرنة:

### الخيار (أ) — سحابي مجاني بدون تثبيت أي برامج (MongoDB Atlas - الأفضل والأسهل):
1. سجل حساباً مجانياً على [MongoDB Atlas](https://www.mongodb.com/atlas/database).
2. أنشئ قاعدة بيانات مجانية (Free Shared M0).
3. اضغط على **Connect** ثم **Drivers** وانسخ رابط الاتصال:
   ```text
   mongodb+srv://username:password@cluster0.mongodb.net/?retryWrites=true&w=majority
   ```
4. ضعه في ملف `.env` مكان `MONGO_URI`.

### الخيار (ب) — تثبيت MongoDB محلياً على جهازك:
- حمّل وثبت [MongoDB Community Server](https://www.mongodb.com/try/download/community) على جهازك، وسيعمل الرابط الافتراضي `mongodb://localhost:27017/` تلقائياً.

### الخيار (ج) — وضع التطوير السريع (بدون MongoDB إطلاقاً):
- قمنا ببرمجة البوت ليعمل تلقائياً بنظام **In-Memory Fallback (محاكاة داخل الذاكرة)** إذا لم يجد MongoDB يعمل، حتى لا يتعطل البوت أثناء التجارب والتطوير.

## الخطوة 7: تجربة البوت داخل تطبيق تيليجرام

1. افتح تطبيق تيليجرام وابحث عن يوزر بوتك الذي أنشأته (مثال: `@AneesStore_bot`).
2. اضغط **Start** (أو أرسل `/start`).

### ماذا ستشاهد؟
- رسالة ترحيبية أنيقة مع **زرين اثنين فقط**:
  - 🛒 **المنتجات**
  - 💰 **رصيدي**

### تجربة استعراض وشراء المنتجات:
1. اضغط على **🛒 المنتجات**:
   - سيقوم البوت بجلب المنتجات فورياً وعرضها في صفحات أنيقة (8 منتجات بالصفحة).
   - ستلاحظ رمز التسليم على كل زر:
     - ⚡ للمنتجات الفورية.
     - 🤝 للمنتجات اليدوية.
   - تنقل بين الصفحات عبر أزرار `◀️ السابق` و `التالي ▶️`.
2. اضغط على أي منتج لعرض تفاصيله (الوصف، السعر، الستوك، نوع التسليم).
3. اضغط على **🛒 شراء الآن**:
   - يطلب البوت تأكيد الشراء.
   - إذا كان المنتج اشتراك **ChatGPT Business**: سيطلب منك البوت إدخال بريدك الإلكتروني لإرسال الدعوة.
   - فور التأكيد:
     - إذا كان فورياً (`is_manual = false`): ستستلم كود المنتج مباشرة في رسالة بتنسيق `<code>الكود</code>`.
     - إذا كان يدوياً (`is_manual = true`): ستظهر لك رسالة: *"✅ تم استلام طلبك! سيتم التسليم خلال دقائق."* مع رقم الطلب.
     - في نفس اللحظة: **تصلك كأدمن رسالة إشعار فورية** تحتوي على اسم العميل، معرفه، المنتج، والمبلغ.

### تجربة فحص الرصيد:
- اضغط على **💰 رصيدي**:
  - يعرض رصيد العميل وإجمالي طلباته.
  - وبما أنك مسجل كـ **Admin** في `.env`، ستظهر لك خانة إضافية تعرض رصيد حسابك المتبقي في API المتجر.

### تجربة أوامر الأدمن:
- أرسل `/sync`: لمزامنة الستوك والمخزون وحفظ الكورسور الجديد.
- أرسل `/api_balance`: لمعرفة رصيدك المالي في المتجر الخارجي.
- أرسل `/orders`: لعرض آخر 10 طلبات تمت في المتجر.
- أرسل `/add_balance USER_ID AMOUNT`: لشحن رصيد لأي مستخدم (مثال: `/add_balance 987654321 15`).
- أرسل `/set_conn CODE`: إذا أردت في المستقبل تغيير كود الاتصال دون إعادة تشغيل البوت.

## الخطوة 8: تشغيل البوت 24/7 باستمرار

حتى يستمر البوت في العمل طوال الوقت حتى عند إغلاق جهاز الكمبيوتر:

### الخيار 1: على سيرفر Linux (VPS / Ubuntu):
يمكنك تشغيله كخدمة في الخلفية عبر `systemd` أو `screen`:
```bash
# باستخدام screen:
screen -S anees_bot
python bot.py
# للخروج مع بقائه يعمل اضغط: Ctrl + A ثم D
```

### الخيار 2: استضافة سحابية مجانية (مثل Render أو Railway):
1. ارفع المشروع إلى مستودع GitHub خاص بك.
2. أنشئ Web Service أو Background Worker على Render/Railway.
3. حدد أمر التشغيل (Start Command):
   ```bash
   python bot.py
   ```
4. أضف متغيرات البيئة الموجودة في `.env` في لوحة تحكم الاستضافة (Environment Variables).

## حل المشاكل الشائعة (Troubleshooting)

### ❓ المشكلة 1: `ValueError: Token must contain a colon`
- **السبب:** لم تضع التوكن في ملف `.env` أو أن التوكن غير صحيح.
- **الحل:** تأكد من نسخ التوكن كاملاً من `@BotFather` ولصقه في `BOT_TOKEN=...` في ملف `.env`.

### ❓ المشكلة 2: البوت لا يرسل إشعارات الأدمن
- **السبب:** قيمة `ADMIN_ID` في ملف `.env` تساوي `0` أو خاطئة.
- **الحل:** احصل على الآيدي الصحيح لحسابك من `@userinfobot` وضعه في `ADMIN_ID`.

### ❓ المشكلة 3: خطأ في الشراء `Insufficient balance`
- **السبب:** رصيدك في حساب API المتجر الخارجي قليل أو 0.
- **الحل:** يمكنك شحن رصيد حسابك في المتجر الخارجي، أو فحص رصيدك بالأمر `/api_balance`.

### ❓ المشكلة 4: مشكلة ترميز الحروف في Windows PowerShell
- تم ضبط البوت تلقائياً ليعمل بترميز `utf-8` على نظام ويندوز لتجنب أي مشاكل في قراءة الحروف العربية.
